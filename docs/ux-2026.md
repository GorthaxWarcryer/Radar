# Azeroth Radar — 2026 UX improvements

**Scope:** Existing Cloudflare Workers app, not the original ChatGPT Site. The original dark Warcraft-inspired visual identity remains; YouTube/Blizzard/Reddit sources and D1 data are preserved.

## Research-based changes

- **Recognition over recall**: clear selected sort and format controls, descriptive navigation, result counts, and obvious data freshness. [Nielsen Norman Group](https://www.nngroup.com/articles/recognition-and-recall/).
- **Progressive disclosure**: prioritize videos and metrics; consolidate advanced search, timeframe and sorting into a tidy filter panel. [Nielsen Norman Group](https://www.nngroup.com/articles/progressive-disclosure/).
- **Accessible interaction**: stronger keyboard focus, larger tap targets, skip navigation, meaningful control names, and reduced-motion behavior. [W3C WCAG 2.2](https://www.w3.org/TR/WCAG22/).
- **Stable fast content**: reserved video image dimensions, first-image priority, subsequent lazy images, and font preconnects. [web.dev image lazy-loading](https://web.dev/articles/browser-level-image-lazy-loading) and [Google Core Web Vitals](https://developers.google.com/search/docs/appearance/core-web-vitals).
- **System status and control**: manual refresh with real source timestamps, graceful transient outages, no auto-refresh interruptions while editing. [Nielsen Norman Group usability heuristics](https://www.nngroup.com/articles/ten-usability-heuristics/).

## UI improvements

1. Refined dark surfaces, contrast, restrained gold accent, spacing, responsive cards, menus and buttons.
2. HOT defaults to Growth sorting while Popular defaults to total Views; the two sections keep their choices independently.
3. Search supports Enter, Escape and slash shortcut (outside input fields), clear state, result counts and contextual no-match feedback.
4. Increased pointer targets, visible keyboard focus, accessible filter labels and skip-to-content.
5. Source timestamps switch to days after 24 hours; HOT sidebar says Hourly instead of misleading Live.
6. Refresh button and stable loading; 60-second refresh pauses when tab hidden or user edits fields, and retains last data on network errors.
7. Better phone and tablet nav, touch-friendly controls, aspect-ratio-safe thumbnails and reduced motion.
8. Reddit remains browser links to public Top Today/Hot, with manual local saves and no Reddit API or scraper.
9. A reliability issue discovered during the UX review was fixed: GitHub HOT snapshots beyond the Contents API 1 MB inline limit now read from the immutable Git blob rather than discarding history.
