# Azeroth Radar — Render deployment guide (v0.3)

The editable rebuild has not yet been deployed. The original ChatGPT Sites website, its data, and its existing automation are separate and must remain untouched.

## Hosting plan and cost

The supplied `render.yaml` Blueprint uses one paid **Starter** web service (approximately $7/month at the current posted price), one 1 GB persistent disk (approximately $0.25/month), and the Frankfurt region. Additional usage may incur charges. Confirm current prices in your Render workspace before approving a deployment. A free web service cannot attach a persistent disk and sleeps after inactivity, which would lose the SQLite database and interrupt the hourly scanner.

## Publish editable code

1. Create a private GitHub repo for Azeroth Radar and upload the files from this ZIP, making sure `render.yaml`, `Dockerfile`, `server.mjs`, `package.json`, `src/`, and `public/` are all in the repository root. Never commit `.env`, keys, SQLite, or real content exports.
2. Connect that GitHub repository to Render (Render > Account Settings > Git Deployment Credentials). Alternatively, have an assistant with GitHub write access create and push the repo.
3. In Render, select **New > Blueprint**, connect the repository, review `render.yaml`, and confirm charges *before* applying the Blueprint. Do not create multiple copies of the service. The Blueprint provisions a web service and one attached disk, and generates a private `ADMIN_TOKEN`.
4. After the first successful deployment, open `https://<assigned-hostname>.onrender.com/api/health`. The result should contain `"ok": true`. Then open the root URL for the actual dashboard. For demo content, click the **Preview demo** toggle; illustrative cards are labeled and are not live information.
5. When the YouTube API key is ready, set `YOUTUBE_API_KEY` and `YOUTUBE_CHANNELS` under **Render > service > Environment** and redeploy. Do not put API keys into the website browser, source repository, or chat. The backend reads server-side variables.
6. Enable Reddit OAuth only if you have approved credentials (`REDDIT_CLIENT_ID`, `REDDIT_CLIENT_SECRET`, `REDDIT_USER_AGENT`). To ingest official sources, provide an approved `OFFICIAL_POSTS_JSON_URL`; that integration is not automatically connected to Blizzard.
7. Test a YouTube scan and verify counts. The HOT growth metric requires at least two real view samples separated in time. Save a bookmark/note and verify it survives a service restart (the database is stored at `/data/azeroth.sqlite`).
8. Verify mobile/desktop layout, both Default/Blackrock Depths themes, HOT/Popular/Stories/Content Creation, background scanning, persistence, and public/private data behavior before announcing the site.

## Security, reliability, and maintenance

- `ADMIN_TOKEN` is generated by Render. It is required for imports, manual scans, bookmarks, notes, and exports. Treat it as a secret and access its value only through the secure Render dashboard.
- The app runs its hourly scanner inside a **single always-on** web process. The Blueprint intentionally uses `numInstances: 1` because the scanner and SQLite are in-process.
- Render's disk mount at `/data` persists across restarts; the remaining container filesystem does not.
- The original ChatGPT Sites site has its own scheduled job. Do not assume its key or schedule works on Render, and do not disable it until the replacement is confirmed operational.
- Future modifications should be made to the same private GitHub repo and pushed to its deployment branch; Render auto-deploys each commit.
- Back up through the protected `/api/export` endpoint. Render also creates disk snapshots, but do not use snapshots as the sole backup.
